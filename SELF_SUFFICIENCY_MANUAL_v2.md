### A. Open any file
1. Go to the repo link above.
2. Click a folder name to go inside. Click a file name to open it.
3. Use the search box at the top ("Go to file", or press the letter t) to find a file by name.

### B. Change a word or a line on a page (no code knowledge needed)
1. Open the file (for example cinelink/live-apps/cinelink.html).
2. Click the pencil icon at the top right of the file.
3. Use your browser's find (Ctrl+F or Cmd+F) to locate the words. Change them.
4. Click "Commit changes" (green button, top right). Type a short note such as "fix wording". Click "Commit changes" again.
5. Wait 1 to 3 minutes. Refresh the live page. Your change is now online.

### C. Add a new file or picture
1. Open the folder where it should go.
2. Click "Add file", then "Upload files".
3. Drag the file in. Click "Commit changes".

### D. Get a link to share
Take the file's path in the repo and put it after the base address:
https://tomdeggs.github.io/BETONIQ-WEST-/ + path
Example: path zeropay_landing.html gives https://tomdeggs.github.io/BETONIQ-WEST-/zeropay_landing.html
This works on iPhone and inside WhatsApp.

### E. If you make a mistake
1. Open the file. Click "History" (top right).
2. Click the last good version. Click the three dots, then "View file", then copy its content back with the pencil.
Everything is versioned, so nothing is lost.
