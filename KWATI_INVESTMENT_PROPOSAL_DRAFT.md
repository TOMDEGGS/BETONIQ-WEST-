Security risk here is localized and opportunistic, not organized insurgency.
4. Benue State — the Otukpo to Makurdi corridor. Rural network "white zones" are common across Benue's LGAs, with well-documented state infrastructure gaps; risk profile is largely communal/opportunistic rather than organized insurgency.

Net effect: Phase 1 now spans four zones instead of three, deliberately weighted toward genuinely underserved rural network gaps rather than active insurgency zones — a materially safer field deployment profile while still proving the core "true offline" claim.
