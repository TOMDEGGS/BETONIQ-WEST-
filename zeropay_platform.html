Technology
How ZerôPâŷ Money Works
A 5-step protocol layer that sits below all existing payment infrastructure — working with Paystack, not replacing it.
1
💳
PUF Hardware Terminal
Physical Unclonable Function silicon chip generates a unique cryptographic fingerprint per device. Cannot be cloned. Cannot be replicated. Every ZerôPâŷ Money terminal has an identity that is physically impossible to forge.
2
🔐
ECC P-256 Signing
Elliptic Curve Cryptography P-256 signs every transaction. Bank-grade encryption at the point of tap. Each transaction gets a unique cryptographic signature tied to both the terminal PUF and the offline token.
3
📡
Distance Bounding Protocol
Anti-relay attack protection. The protocol verifies the physical proximity of the NFC card to the terminal in real time. Relay attacks, MITM attacks, and card cloning are mathematically impossible.
4
🪙
Offline Cryptographic Tokens
72-hour Time-To-Live tokens enable transactions with zero internet connectivity. Tokens are pre-issued, cryptographically signed, and verified locally. When connectivity returns, batch reconciliation with Paystack confirms every transaction.
5
☀️
Solar Mesh Hub Relay
Solar-powered relay nodes form a self-healing mesh network. Transactions hop node-to-node across 100km+ with zero GSM, zero internet, zero grid power. 72-hour supercapacitor + lithium backup aligns with token TTL.
6
🏦
Paystack Settlement Rail
ZerôPâŷ Money is NOT a competitor to Paystack — it is the protocol layer that brings Paystack to the last mile. When connectivity returns, batch queues sync, Paystack settles, MFB holds float, IMTO handles cross-border FX.

6 Attack Vectors
ZerôPâŷ Money: Zero Successful Attacks
🔴
Relay / MITM Attack
Attacker intercepts NFC signal between card and terminal. Distance Bounding Protocol detects the relay delay in nanoseconds. Transaction cancelled.
✅ DEFEATED — Distance Bounding
🔴
Device Cloning
Attacker attempts to clone the terminal hardware. PUF fingerprint is physically unique — cloned hardware produces a different fingerprint. Rejected instantly.
✅ DEFEATED — PUF Hardware
🔴
Replay Attack
Attacker captures a valid transaction and replays it. ECC signature contains a unique nonce. Replayed transaction signature fails verification immediately.
✅ DEFEATED — ECC Nonce
🔴
Token Forgery
Attacker attempts to create or modify an offline token. Tokens are signed by PUF-tied keypair. Any modification breaks the signature. Forgery is mathematically impossible.
✅ DEFEATED — PUF + ECC
🔴
Rogue Mesh Node
Attacker inserts a fake relay node into the mesh network. Hop-chain verification detects the unsigned node. Transaction is not propagated.
✅ DEFEATED — Mesh Verification
🔴
AI Bypass Attempt
AI-generated synthetic payment patterns attempt to spoof valid transactions. PUF + Distance Bounding cannot be mimicked by software. Hardware layer is AI-proof.
✅ DEFEATED — Hardware Layer
